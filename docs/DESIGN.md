# Design

> Solum 壳层前端（`crates/solum-app/dist/index.html`）的视觉系统。单文件、vanilla JS、无构建管线；所有 token 以 CSS 自定义属性定义在该文件 `:root` 中，本文档是其人类可读快照（2026-08-13 账户外壳与工作台排版版）。改样式请先读 [PRODUCT.md](PRODUCT.md) 的设计原则。

## Theme

「黑白编辑部与微粉信号」——安静、清楚、有秩序的私人档案与行动界面。大面积只使用黑、白与中性灰；微粉只以小圆点、细线或极淡雾面出现，表示在线、待处理或选中提示，不能铺成主按钮。主动作统一使用高对比黑白，危险操作继续使用红色。深浅两套主题经 `prefers-color-scheme` 自动切换，均为一等公民。

风格来源：用户提供的四张移动端参考图。提取其高留白、清晰字级、极轻轮廓、黑色实心动作与微粉信号语言；不复刻超大标题、胶囊堆叠和装饰性构图。内容结构由 Solum 的对话、日程、记忆、邮箱、同步、隐私和 Guard 等真实能力决定。

色彩策略：**Editorial monochrome**（中性面 + 信号色占比 ≤3%）。

语义规约：微粉 = 新状态/待处理/在线/选中提示；黑色实心 = 主动作；绿 = 好的稳态；红 = 危险与破坏性操作**专用**（"忽略建议"这类中性动作不许用红）；待定状态用中性空心圆点，不占用彩色。

## Typography

- 字族：系统栈 `"Segoe UI Variable Text", "Segoe UI", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei UI", ... sans-serif`；等宽 `ui-monospace, "Cascadia Mono", Consolas` 用于时间戳、数字、工具名、路径。个性由色彩与图标承担，不引入网络字体（离线应用 + 中文字体体积）。
- 尺度：12 / 13 / 14 / 16 / 18 / 22 / 28 / 36。应用品牌首启标题最高 36px；视图标题桌面 28px、移动端 24px；面板标题 18–22px，正文 15–16px。字号不跟随视口宽度缩放。
- 全站 `letter-spacing: 0`。中文和 UI 控件禁止负字距与装饰性大写疏排；层级由字号、字重、色彩和间距表达。
- **须读文字下限 12px**（底栏标签、会话元信息也不例外）；提示/说明类统一 13px（全局 `.hint`）。11px 及以下只允许出现在纯装饰（库路径）上。（2026-07-20 密度重构定）
- 正文行高 1.55–1.8；简报正文限宽 68ch；数字一律 `font-variant-numeric: tabular-nums`。
- 时间戳组件 `fmtDT`：日期半透明弱化 + 时间保持墨色，等宽。

## Iconography

24 网格手绘 SVG 线条图标（`ICONS` 表，`stroke="currentColor"`，stroke-width 1.75，圆头圆角），全站唯一图标词汇，**禁止 emoji**。新图标必须手绘同笔触补进 `ICONS`，不引入图标库。

## Spacing / Radius / Elevation

- 间距 4pt 阶梯：4/8/12/16/24/32；组内紧（8-12）、组间松（24-42，`.block` 之间 42）。
- **行与单元格不许贴边**：列表行 `12px 10px`、表格 td `11px 12px` / th `8px 12px`——2026-07-20 重构前的 `10px 2px` 贴边内边距是「过密」观感的主源之一，不要改回去。
- 圆角：`--r-sm 4px`（标签）/ `--r-md 6px`（按钮、输入框）/ `--r-lg 8px`（卡片、横幅、输入区、模态）。不使用文字胶囊表达普通命令；熟悉动作优先图标并提供 tooltip/aria-label。
- 阴影极轻：层级主要靠发丝线、留白和第二中性层；悬浮导航与模态可用扩散阴影。**禁止卡片套卡片**。
- z-index 语义阶梯：`--z-sticky 10 / --z-backdrop 40 / --z-modal 41 / --z-toast 50`，禁止随手 999。

## Components

- **按钮** `.btn`：默认（描边）/ `primary`（近黑填充+白字）/ `danger`（红字描边，hover 红雾）/ `danger-fill`（模态确认专用）/ `icon`（幽灵图标钮，`::before` 扩到 ≥44px 触控区）/ `sm`。`:active` 有轻微缩放与下压反馈。
- **分段控件** `.seg`：发丝轮廓槽 + 活动片黑色实心（白字），用于二级导航与主动度三档。
- **开关** `.switch`：34×20 轨道，选中轨道为琥珀灯色。
- **标签** `.tag`：方角 6px 小标签，`accent/ok/danger/plain` 四变体；**状态点** `.st`/`.sdot`：实心绿=完成、琥珀=到点、空心=待定、灰=沉默。
- **数据表** `.dt`：无竖线、发丝行分隔、表头 12px 弱化、行 hover、数字列等宽。
- **列表行** `.row`/`.ev-row`/`.notif-row`：扫读型数据用行不用表；日程行 = 等宽时间列 + 标题 + 类型标签 + 弱化元信息。**带操作按钮的数据一律用行**（`.notif-row`，允许折行）——表格的操作列在窄屏横滚下会被藏出屏幕（2026-07-20 提醒列表弃表改行的原因）。
- **状态行** `.statusline`：灰点/语义点 + 13px 弱化文字 + 详情进 `title`。**陈述性稳态一律用它，琥珀横幅只留给需要用户注意或行动的场景**——否则「灯亮即有事」被状态噪音稀释（2026-07-20 语义收紧）。
- **折叠块** `details.fold`（低频/进阶表单默认收起）与侧栏 `#devFold`（调试项）：原生 details，熟悉控件不发明交互。**红线：折叠前必须确认「空状态下用户完成首次配置的唯一入口」不在里面**——在里面就要按状态自动展开（邮箱未配账户、人格未设、导入结果填表三处已有此分支）。折叠服务于已配置好的老用户，不能让新用户付代价。
- **抽屉内详情头** `.drawer-detail-head`：返回图标 + 名称一行（44px），次要操作收进「⋯」浮窗。**主视图的 `.vhead` 不可用于抽屉**——24px 标题 + 一排按钮在 460px 下实测 171px、占抽屉两成高度且 sticky 常占。
- **表单**：`.formcol` 限宽 520px；短字段用 `.fieldrow`（`auto-fit minmax(150px,1fr)`）并排，窄屏自动落单列——禁止把输入框+多个下拉+按钮挤进一行 btnrow。
- **气泡**：用户 = 琥珀薄纱底 + 琥珀发丝边（右下角 6px）；agent = 内容面 + 发丝边（左下角 6px）；内嵌 GenUI 卡片用 `--inset` 底。**GenUI 外观全部固定在 `.gc-*` 类中，信封不能指定颜色/尺寸（架构 §3.9 防 UI 注入）**。
- **横幅** `.banner`：中性底 + 发丝边，必要时用微粉信号点提示。危险与强警示仍走红色语义。
- **模态**：仅用于高危确认与不可逆删除（product 原则：模态是最后手段）；红色确认钮 + 后果预览红雾块；Esc/点遮罩可关。
- **toast**：底部居中、悬于输入区之上（bottom 94px），反色面 + 语义色小图标。
- **空状态**：图标 + 一句现状 + 一句怎么让它有内容，禁止裸"（空）"。

## Motion

动效遵循 GSAP core/timeline/performance 技能的约束，但保持本仓零依赖：使用同等的时间线、错峰与 transform/opacity 原则，通过 Web Animations API 在单文件内实现，不引入 npm/CDN。视图切换 260–420ms（导航状态 → 标题 → 内容短时间线）、身份入口 420ms、消息升入 220ms、模态 220ms、导航选中 180ms、品牌信号呼吸 3.2s（唯一常驻动效）。所有序列可被下一次导航中断，离屏动画会取消；全部动效在 `prefers-reduced-motion: reduce` 下退化为即时。禁止弹跳/弹性曲线，禁止动画 width/height/top/left，也禁止无意义的循环装饰。

## Layout & Breakpoints

- **≥900px**：240px 固定侧栏（Solum 品牌 + 今天 / 记忆 / 计划 / 搜索四个根入口 + 完整能力工具区；页脚是可点击的账号身份与同步状态）+ 主区。主内容限宽 1120px；侧栏和内容是同一应用壳层，不做浮岛式大卡片。
- **≥1000px**：对话页在消息流左侧出现 210px 会话栏；窄屏仍以会话下拉框与新建按钮完成同一操作。
- **≥1240px**：对话页右侧再显示 300px「今日面板」（到点提醒/接下来/待处理建议）。（2026-07-20 从 1360 下调：1280 宽的常见笔记本窗口此前看不到面板。）
- **<900px**：顶部品牌栏（左侧 Solum，右侧账号头像/状态入口 + 到点角标）+ 贴底矩形标签栏（今天 / 记忆 / 计划 / 搜索四项，64px+safe-area）；点账号入口打开身份与完整能力面板，模拟时钟不暴露。
- **账户入口**：隐私同意后的首次身份选择使用全屏工作区，不是营销 hero。左侧/上方表达本地隐私承诺，主区直接提供登录、注册、访客三条动作；已登录后同一身份显示在桌面侧栏页脚和移动端顶栏。受限工具保留入口并显示锁图标，点击统一进入账户工作区。
- **视图壳固定（2026-07-20）**：`.vhead`（标题 + 主操作）吸附在各视图滚动口顶部（sticky），只有数据区在下面滚；短页面完全不滚。对话页恒为「滚动消息流 + 底部固定输入区」的列布局。
- 二级导航（记忆、计划组内多视图）为主区顶部分段控件；每组记住最后停留视图。**设置属于工具层且保持多级导航**：目录页（图标 + 名称 + 一句说明的 `.nav-menu`）→ 二级详情页，详情页顶部为面包屑返回（`.crumb-back`，「← 设置 / 当前页」）。不能由用户数据或新连接器扩张四个顶层根入口。
- **工作台并入对话（2026-07-20）**：「资料 / 组件」不再是顶层组，入口在对话输入框「+」浮窗菜单（`#composerMenu`），内容以右侧抽屉呈现（`#drawer`，宽 min(460px, 100vw)，z 在模态之下——抽屉里的高危确认模态必须能盖住它）。Esc / 遮罩点击关闭，焦点还给开启者。**窄屏下分段控件换行铺开而非横向滚动**——设置组 6 项曾在 390px 溢出 2px 且滚动条被藏，入口被静默截断（2026-07-20）。
- 触屏（`pointer:coarse`）下 `.btn.sm` 与 `.qmark` 用伪元素扩到 ≥44px 命中区，不放大视觉尺寸。

## Voice

管家式中文：直接、简短、有主语（"到点我会亮灯""这属于高危操作，我不能直接执行"）。危险操作措辞严肃完整（后果预览 + 不可恢复声明）。不用感叹号堆热情，不用 emoji。
