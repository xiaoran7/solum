# Solum 视觉与交互

设计方向为克制的“纸墨/琥珀台灯”：温暖中性色、清晰层级和低刺激反馈。视觉不能牺牲信息密度、对比度或系统可访问性。

- 主导航稳定；今天、记忆、计划、搜索是核心入口，账号与工具集中管理。
- 重要状态使用文字 + 图标，不只靠颜色；错误给出可恢复动作。
- 所有写入先显示来源和结构化预览；Guard 对话明确区分预览、确认和执行结果。
- 移动端优先单列、可触达的控件和系统返回；桌面扩展宽度但不改变语义。
- 动画短、可中断，并尊重 reduced motion；加载态不伪装为成功。
- 最小点击区、字号、对比度和键盘焦点需在真实渲染中验证。

前端仍是静态 Vanilla JS。不要为视觉重构引入框架或 npm 依赖。
