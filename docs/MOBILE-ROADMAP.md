# 移动端路线

## 当前

- Android/Tauri 是主仓移动实现，共享 Rust core 与生产服务端。
- HarmonyOS 为 `../harmony` 独立 ArkTS 仓，通过固定夹具对齐同步/备份协议。
- iOS 尚未立项；不能从目录占位推断支持状态。

## 优先级

1. 生产 Android 真机：rustls 网络、后台提醒、重启恢复、账号隔离、通知白名单与 Health Connect 授权边界。
2. Android↔HarmonyOS 加密备份/恢复真机互通与错误注入。
3. 发布合规：权限、隐私清单、签名、升级/回滚和商店材料。
4. 再评估 iOS、浏览器扩展和桌面 Agent，不扩大明文云端范围。

每个平台必须单独证明构建、安装、权限、后台行为和升级；共享协议测试不能替代设备 E2E。
