# LLM Provider 配置

客户端不保存第三方 API Key，统一通过 Solum 服务端代理调用模型。Provider、模型目录、额度和路由以服务端运行配置和 `/v1/models` 等实际响应为准，文档不固定生产模型名。

## 规则

- 未登录/访客不调用云端 AI；网络或服务失败时保留本机 ingest、搜索和提醒。
- 每次请求只发送当前任务所需的最小上下文；`local_only` 通知、未授权健康数据和完整本机数据库不得上传。
- 服务端按租户鉴权、限额、超时和审计；错误不能回显 provider key、内部 URL 或上游原文。
- 客户端处理模型列表变化、额度不足、429、超时和非结构化输出；模型输出通过 schema/Guard 后才能改变状态。

本地开发可使用 mock 或隔离服务；任何真实 key 仅通过环境/secret manager 注入。
