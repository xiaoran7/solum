# Solum 隐私边界

## 数据分类

- **本机明文**：输入、日程、提醒、记忆、行为日志、人格、健康采样、聊天与通知正文。
- **云端元数据**：账号、会话、设备、用量和福利告警的最小字段。
- **端到端密文**：同步 oplog、备份和附件；服务端不得持有解密材料。
- **可选云端 AI**：只发送当前回复所需的最小上下文，并在界面中可识别。

第三方通知入库即标记 `local_only`，永不作为 recall 或云端 LLM 明文上下文。“通知上云”开关只能控制新通知是否允许用于云端 AI，不能关闭或绕过密文同步。

## 用户控制

- 首启同意、权限按需申请、连接器可关闭。
- 支持本机导出、加密备份、恢复与删除；破坏性操作走 Guard。
- 访客与账号按 profile/UUID 隔离，退出后切回 guest。
- 日志、截图和测试夹具必须脱敏；真实通知、健康与账号数据不进入仓库。

隐私政策、商店清单和权限声明在发布前按实际代码/服务重新核对。
