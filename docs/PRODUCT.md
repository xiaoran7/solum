# Solum 产品原则

Solum 是“先核对、再入库”的本地优先 Personal Agent，不是替用户自动执行一切的聊天机器人。

## 核心旅程

1. 从对话、分享、通知白名单或健康/日历连接器接收输入。
2. 展示解析结果与来源，让用户修正或确认。
3. 写入本机事件、提醒、记忆或行为日志。
4. 在需要时生成建议/复盘；危险动作先经过 Guard。

## 体验原则

- 离线可用，联网状态和降级原因可见。
- 用户知道数据来自哪里、将写到哪里、是否会发给云端。
- 建议可忽略，提醒可追溯，自动化可关闭。
- 访客和账号数据完全分区；退出后不泄露账号空间。
- 未接通能力明确标注，不能用占位 UI 暗示已经可用。
