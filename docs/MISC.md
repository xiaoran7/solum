# Solum 当前决策

- Rust/Tauri 主仓保留共享 core、Android 客户端和生产服务端；HarmonyOS 独立实现，不复制主仓产品协议。
- 同步 KDF 采用可由浏览器 SubtleCrypto 对拍的 PBKDF2；这是运维控制台互操作取舍，不代表一般密码存储建议。
- Android TLS 使用 rustls，避免交叉编译依赖系统 OpenSSL。
- 前端保持 Vanilla JS 静态单页，降低移动包和供应链复杂度。
- 云端 AI 与同步是独立能力：关闭明文 AI 不得关闭端到端密文同步。
- 生产域名、模型、服务版本、设备状态和测试计数属于易变事实，只在带日期证据中记录并在执行前复核。
