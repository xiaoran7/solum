# Agent 工具契约

工具是受控领域命令，不是任意代码执行。每个工具声明输入 schema、权限、读写范围、幂等性和是否需要 Guard。

- 只读工具可查询当前 profile 的本机数据，并返回最小结果。
- 写工具先生成预览；破坏性或外部副作用必须使用 Guard 一次性令牌。
- `Grant` 只能由 Guard 模块签发，调用方不能构造或复用。
- 工具执行写 append-only 审计，日志不含密钥、通知正文或健康明细。
- 时间由调用方注入；网络失败不得回滚已完成的本机 ingest。
- 模型只能建议调用，最终参数必须经 schema、租户和业务规则验证。

精确工具名与参数以 `solum-core`/Tauri command 和测试为准。
