# Solum Server

生产服务端实现位于 `crates/solum-sync-server`。它负责账号/会话/设备、模型目录与 AI 代理、端到端密文同步/备份、恢复信封、用量和福利告警；不得保存可查询的个人明文正文或客户端解密密钥。

## 运行原则

- 配置和凭据通过环境或 secret manager 注入；仓库不保存生产 token、数据库密码或上游 key。
- 所有业务按账号/设备做租户校验；refresh、恢复码、改密和设备撤销写安全审计。
- 同步/备份正文按不透明密文处理；服务端可校验大小、摘要、代际和配额，但不能解密。
- AI 端点限额、超时、最小日志和上游错误脱敏；provider/模型是易变配置。
- 福利告警支持受控测试状态、幂等和自动清理，不能写入真实私人正文。

## 验证与部署

先运行 workspace test/clippy/fmt，再对隔离数据库执行服务端集成测试。部署时记录 commit、迁移、镜像摘要和健康基线；主机 API 成功只证明服务端，不替代 Android/HarmonyOS 设备验证。

精确路由和环境变量以当前 server 源码/配置为准，避免在 README 复制会快速过期的生产域名、模型和版本。
