连接

token 是部署时设的 SOLUM_SYNC_SERVER_TOKEN，和设备同步用的是同一把。 忘了的话去部署这台服务的 1Panel → 容器 → 编排 → solum-sync → 编辑，「环境变量」框里就是。 这里只用它做 API 鉴权，不会把它发到别处，只存在你自己浏览器的 localStorage 里。

在浏览器本地按跟设备端一样的方式（PBKDF2 + HKDF）算出 token，只存派生结果，密码本身不会保存、不会发出去。
